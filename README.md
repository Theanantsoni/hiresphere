 💼 HireSphere – MERN Stack Job Portal

HireSphere is a full-stack MERN Stack Job Portal designed to simplify the recruitment process by connecting job seekers and recruiters on a single platform.

The application provides two dedicated portals:

- Candidate Portal – Search, filter, and apply for jobs while managing profile and resume.
  
- Recruiter Portal – Post jobs, manage applicants, review resumes, track hiring progress, and analyze recruitment statistics.

HireSphere is built with scalability, secure authentication, responsive design, and clean MERN architecture in mind.

 ⚙️ Application Workflow

 👨 Candidate Workflow

1. Register/Login using Clerk Authentication.
2. Complete profile information.
3. Upload resume.
4. Browse available jobs.
5. Search jobs using keywords.
6. Filter jobs by category and location.
7. Explore verified companies.
8. View detailed company profiles.
9. Apply for preferred jobs.
10. Track application status.
11. Update profile and resume whenever required.

---

 🏢 Recruiter Workflow

1. Login securely.
2. Complete company profile.
3. Add company employees.
4. Publish new job openings.
5. Manage active and hidden jobs.
6. Review applicants.
7. View candidate resumes.
8. Accept or reject applications.
9. Analyze hiring statistics.
10. Track recruitment performance.


 Install Server

```bash
cd server

npm install

npm start
```
